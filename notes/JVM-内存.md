# JVM内存模型

JVM 内存模型把运行时内存划分为堆、虚拟机栈、本地方法栈、方法区与程序计数器。堆是对象分配的主要区域，是垃圾回收的主战场。虚拟机栈保存栈帧，每个栈帧包含局部变量表与操作数栈。方法区存储类元信息与常量池。

# 垃圾回收

垃圾回收（GC）负责回收堆中不再被引用的对象。常用的垃圾收集器包括 Serial、Parallel、CMS 与 G1。判断对象是否存活的主流算法是可达性分析，从 GC Roots 出发遍历引用链。

# 堆与栈

堆与栈的区别：堆内存存放对象实例，由垃圾回收统一管理；虚拟机栈存放方法调用的栈帧，方法结束即出栈。堆内存又分为新生代与老年代，新生代分为 Eden 与两个 Survivor 区，对象先在 Eden 区分配，经过多次 Minor GC 存活后晋升老年代。
