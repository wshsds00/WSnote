# 向量检索

RAG 检索为什么用向量检索：向量检索把查询与文档都编码成向量，通过向量相似度召回语义相近的片段，能理解同义词与语义，弥补关键词检索的不足。

# 向量化

向量化（embedding）是把文本转成固定维度的稠密向量表示。常用的中文 embedding 模型如 bge-small-zh。向量之间用余弦相似度衡量语义距离。

# 混合检索

混合检索同时使用 BM25 稀疏检索与稠密向量检索，再用 RRF 融合排序，兼顾关键词精确匹配与语义泛化。
