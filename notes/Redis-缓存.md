# 过期策略

Redis 缓存过期策略主要有两种：惰性删除与定期删除。惰性删除在访问键时才判断是否过期，定期删除周期性随机抽查一批键。Redis 用 TTL 记录键的剩余存活时间，过期后配合内存淘汰策略回收。

# 缓存穿透击穿雪崩

缓存穿透、缓存击穿与缓存雪崩是 Redis 缓存的三个经典问题。缓存穿透指查询不存在的数据，请求直接打到数据库，可用布隆过滤器解决；缓存击穿是热点键过期瞬间大量请求涌入，可用互斥锁解决；缓存雪崩是大量键同时过期导致数据库压力骤增，可给过期时间加随机值解决。

# 持久化

Redis 持久化有 RDB 快照与 AOF 追加日志两种方式。RDB 定期生成内存快照，AOF 记录每次写命令，混合持久化结合两者优点。
